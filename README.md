# Porin kopterilento

Selaimessa toimiva 3D-helikopteripeli Porin keskustasta. Pelkkiä staattisia tiedostoja, ei build-vaihetta.

## Julkaisu Renderissä
1. Vie tämän kansion sisältö GitHub-repoon (tiedostot repon juureen).
2. Renderissä: New > Static Site > valitse repo.
3. Build Command: tyhjä (tai `true`), Publish Directory: `.`
   (tai New > Blueprint, jolloin `render.yaml` hoitaa asetukset).
